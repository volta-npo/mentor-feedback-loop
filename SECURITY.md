# Security Policy: Mentor Feedback Loop

## Data handled

This local-first product may contain student and chapter data. Data stays in the browser unless a user exports it.

## Product-specific risks

- Do not enter raw passwords, API keys, bank credentials, private keys, or regulated sensitive data.
- Treat exported JSON/CSV/Markdown as client records and store them in approved Volta project folders.
- Verify evidence before using any generated packet for owners, sponsors, funders, or public reporting.
- For this product's domain, review these gates before handoff: Every comment needs severity/owner, Blockers require resolution, Stale feedback flagged.

## Reporting

Report vulnerabilities privately to Volta maintainers before public disclosure.
