## Workbench

Mentor Review Loop

Feedback comments

- Resolution Rate
- Actionability
- Mentor Load

## Domain rows

- Feedback request created
- Artifact linked
- Mentor assigned
- Comments categorized
- Severity assigned
- Owner assigned
- Resolution evidence added
- Growth reflection exported

- Review packet
- Action item report
- Growth reflection

- Every comment needs severity/owner
- Blockers require resolution
- Stale feedback flagged
